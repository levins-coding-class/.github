# Levin's Coding Class

Willkommen bei **Levin's Coding Class** – einem Programmierkurs für Kinder, der zeigt, wie Entwickler wirklich arbeiten.

## Was ist diese GitHub-Organisation?

Diese GitHub-Organisation ist der zentrale Ort für unsere Coding Class Gruppe. Hier organisieren wir uns, teilen Projekte und tauschen uns aus.

### Für Mentees

- **Eigene Projekte hinterlegen** – Speichere deine Projekte hier und arbeite gemeinsam mit anderen daran
- **Sich austauschen** – Schau dir an, woran andere arbeiten, gib Feedback und lerne voneinander
- **Gemeinsam lernen** – Nutze die Discussions für Fragen an die Gruppe

### Für Eltern

- **Fragen stellen** – In den [Discussions](https://github.com/orgs/levins-coding-class/discussions) können Fragen zur Coding Class gestellt werden
- **Antworten finden** – Stöbere in bereits beantworteten Fragen anderer Eltern

## Zugang zur Organisation

Teile dieser Organisation sind zugangsgeschützt. Um Mitglied zu werden:

1. Erstelle einen kostenlosen [GitHub-Account](https://github.com/signup)
2. Schreibe eine E-Mail an [post@levinkeller.de](mailto:post@levinkeller.de) mit deinem GitHub-Benutzernamen
3. Du erhältst dann eine Einladung zur Organisation

## Was wir lernen

- **Git & GitHub** – Versionskontrolle wie die Profis
- **VS Code** – Die Entwicklungsumgebung der Wahl
- **Web-Entwicklung** – React, Astro und mehr
- **Eigene Projekte** – Von der Idee zur fertigen Anwendung

## Unsere Philosophie

- Lernen im eigenen Tempo
- Fehler machen ist erlaubt und erwünscht
- Gemeinsam Probleme lösen
- Echte Tools statt Spielzeug-Editoren
